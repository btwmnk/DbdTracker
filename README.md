# DBD Tracker

**Статистика Dead by Daylight по ссылке на Steam-профиль — прямо поверх игры.**

Вставил ссылку в лобби → увидел ранг, побеги, генераторы, часы и баны игрока → закрыл.

## Возможности

- **Вход через Steam** — пароль вводится только на сайте Steam, программа получает лишь твой SteamID.
- **Поиск любого игрока** по ссылке `steamcommunity.com/profiles/…`, `…/id/ник` или по SteamID64.
- **Мини-окно поверх всех окон** — для лобби: `Ctrl+Shift+D`, ссылка из буфера вставляется сама, `Esc` — спрятать.
- **Свои карточки в мини-окне** — выбираешь, что видеть (ранги, побеги, генераторы, сундуки, тотемы, спасения…) и в каком порядке.
- **Ранги выжившего и убийцы** текущего сезона (Пепел IV … Радужный I).
- **Точная статистика**: побеги, генераторы, лечение, спасения, проверки навыка, жертвы, мори, очки крови и ещё около 40 показателей.
- **Достижения и адепты** выживших и убийц, вехи (100 побегов, Радужный I и т. д.).
- **Пометка «новичок»** — мало часов, свежий аккаунт Steam или почти нет достижений.
- **Баны Steam** (VAC, игровые) — видны даже у закрытых профилей.
- **Трей и автозапуск**, недавние игроки, русский и английский язык, тёмная тема.

## Как пользоваться

1. Запусти `DbdTracker.exe` и нажми **«Войти через Steam»** (или «Продолжить без входа» — тогда доступен только поиск).
2. **Мой профиль** — твоя статистика. **Поиск игрока** — вставь ссылку на чужой профиль.
3. В лобби: скопируй ссылку на профиль игрока и нажми **Ctrl+Shift+D** — мини-окно откроется и само найдёт игрока.

Чтобы мини-окно было видно поверх игры, запускай DBD в режиме **«Без рамки» (Borderless)** или **«В окне»**.

### Ключ Steam API (необязательно, но рекомендуется)

Без ключа видны ник, часы (если игрок запускал DBD последние 2 недели), достижения и адепты.
С ключом — ранги, побеги, генераторы, баны и все остальные цифры.

1. Открой https://steamcommunity.com/dev/apikey и войди в Steam.
2. Скопируй ключ (32 символа) в программу: **Настройки → Ключ Steam Web API → Проверить и сохранить**.

Ключ хранится **зашифрованным только на твоём компьютере** (Windows DPAPI) и отправляется только в Steam.
Никому его не показывай.

## Частые вопросы

**Почему у игрока нет статистики?**
Он скрыл «Сведения об играх» в настройках приватности Steam. Такую статистику не видит ни одна программа или сайт — открыть её может только сам игрок. Если ты уже смотрел этого игрока, когда профиль был открыт, программа покажет последние сохранённые цифры с датой.

**Где программа хранит данные?**
В `%LocalAppData%\DbdTracker`: настройки, зашифрованный ключ, недавние игроки, снимки статистики, журнал ошибок.

**Это безопасно для аккаунта DBD?**
Программа не трогает игру и её файлы — она только читает публичные данные Steam через официальный Steam Web API.

## Сборка из исходников

Нужны Windows 10/11, Visual Studio 2022 (нагрузки «.NET desktop development» и «Windows App SDK / WinUI») и .NET 8 SDK.

```cmd
git clone https://github.com/ТВОЙ_НИК/DbdTracker.git
cd DbdTracker
publish.cmd
```

Готовый файл появится в `publish\DbdTracker.exe`.
Для отладки открой `DbdTracker.sln`, выбери **Debug | x64** и нажми F5.
